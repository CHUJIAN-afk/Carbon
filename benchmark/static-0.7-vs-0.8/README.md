# 0.7 与 0.8：冻结 tick 的静止场景单次对照

这是最终定稿前的历史实验；当前默认值、开关语义及最终成绩以 [0.8 最终对照](../final-0.8/README.md) 为准。

按本次要求，两版均开启 `skipVisibilityChecks=true`，各采集一次连续 30 秒数据，先测 0.7，再测 0.8，没有重复采样。0.8 的产品默认值仍为关闭，仅测试配置开启。未修改产品代码，也未增加冻结 tick 专用路径。

10000 个下界合金剑实体全部落地，使用正常重力和碰撞；玩家固定在 `(0,200,-10)`，yaw/pitch 均为 0，距离最近物品 11.00009 格。客户端与服务端均冻结 tick，相机静止，不强制重建缓存，关闭物理化效果。两版全程均绘制 10000 个物品实例和 17030 个阴影实例。

硬件为 Intel Core i7-12800HX、NVIDIA GeForce RTX 4070 Laptop GPU；Minecraft 1.21.1、NeoForge 21.1.238、Sodium 0.8.13、Lithium 0.15.4、JetBrains Runtime 21.0.11。实际分辨率 2560×1600 全屏，FOV 70，实体距离 200%，关闭垂直同步，隐藏 HUD，帧率无限制。

0.7 使用提交 `017d0b1` 的完整源码直接编译；0.8 使用 `a7daba1`，构建检查 `gradlew.bat build --offline` 通过。两版使用相同的采集辅助模组，该辅助模组不取消物品实体 tick。采集仅在窗口获得焦点时开始，两段均持续获得焦点，失焦重启次数为 0，OpenGL 错误为 0。

平均 FPS 为帧数除以累计帧间隔；1% / 0.1% low 为最慢 `ceil(帧数×比例)` 帧的平均帧时间再取倒数，不等于帧时间分位数的倒数。

每约 2 秒记录进程和 GPU 占用，以下均取对应采集窗口内样本。CPU 的 100% 表示一个核心的等效执行时间。

| PixelSky 主进程 CPU 峰值 | 48.60% | 57.28% |

本次观察到平均帧率略降、low 略升，但后台进程负载并不完全一致，且 0.8 重新载入存档后，在冻结前推进了 20 个游戏 tick，物品动画相位不同。各版本仅一次 30 秒样本，不足以确认小幅变化的统计显著性或长期稳定性。超过 5 ms 的帧仍然存在，不能据此宣称周期性低帧已消除。两段均无缓存重建，本次结果仅反映静止冻结场景。

结构化数据、前后场景快照、进程 PID、采集时间和原始数据 SHA-256 见 [results.json](results.json)。原始逐帧 CSV 与占用记录保存在本地忽略目录 `build/rebuild-probe/results/static07-on*`、`static08-on*`。测试后已关闭游戏，恢复原有视频辅助模组和窗口选项，移除临时 Sodium/Lithium 测试副本；测试配置中的 `skipVisibilityChecks=true` 保留。未改动 `release-video/` 或其他分支。
