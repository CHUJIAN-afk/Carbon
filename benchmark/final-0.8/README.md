# 0.8 最终对照成绩

最终版本为 `1.21.1.8`。视锥策略恢复为 0.7：`skipVisibilityChecks` 默认开启，同时跳过视锥和遮挡检查，渲染距离限制始终有效；仅转向时继续复用场景。摄像机后的物品也保留在缓存与实例数据中。关闭该开关后恢复完整可见性检查。

保留 0.8 的 `cacheUpdateBudgetMs`，默认 2 ms，范围 0–20 ms，0 表示当帧处理完队列；实例与阴影的新数据准备完成前继续绘制旧场景。

## 方法

10000 个下界合金剑实体全部落地，正常重力与碰撞。玩家固定于 `(0,200,-10)`，最近距离 11.00009 格，保持水平视角。客户端与服务端均冻结 tick，测试辅助模组不取消物品实体 tick，产品也没有冻结专用快速路径。

0.7 使用提交 `017d0b1` 的完整源码直接编译，沿用先前已采集的对照，没有再次采样。0.8 回退后重新采集一段连续 30 秒数据，前 15 秒静止，后 15 秒按客户端 tick 更新 `yaw=5×sin(秒数)`。两版都设置 `skipVisibilityChecks=true`，物理化关闭，不强制标脏。

Intel Core i7-12800HX、NVIDIA GeForce RTX 4070 Laptop GPU；Minecraft 1.21.1、NeoForge 21.1.238、Sodium 0.8.13、Lithium 0.15.4、JetBrains Runtime 21.0.11。2560×1600 全屏，FOV 70，实体距离 200%，关闭垂直同步，帧率无限制，隐藏 HUD。两段采集均持续获得 GLFW 焦点，失焦重启次数为 0，OpenGL 错误为 0，全程为 10000 个物品实例、17030 个阴影实例。

本次相对 0.7，静止阶段平均 FPS / 1% low 高 8.97% / 8.94%，转向阶段高 8.41% / 3.80%。回退后没有再因转向触发重建；但仍存在 13.22 ms 的长帧，不能据一次样本宣称全部低帧或周期性波动已消除。两段均无缓存重建，因此本次成绩不衡量 2 ms 更新预算的性能。
